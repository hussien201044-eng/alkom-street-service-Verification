# admin-bot-pilot

واجهة تجريبية مستقلة للروبوت الإداري لمنصة خدمات الشارع ونادي الكوم الأخضر.

## الرفع إلى GitHub دون المساس بالموقع الرئيسي
1. افتح المستودع `alkom-street-service-Verification`.
2. أنشئ مجلدًا جديدًا باسم `admin-bot-pilot` من خلال مسار الرفع.
3. ارفع الملفات الثلاثة الموجودة داخل هذا المجلد إلى ذلك المسار:
   - `index.html`
   - `README.md`
   - `.nojekyll`
4. لا ترفع `index.html` إلى جذر المستودع، ولا تستبدل أي ملف في الجذر.
5. بعد إتمام الرفع اختبر:
   `https://hussien201044-eng.github.io/alkom-street-service-Verification/admin-bot-pilot/`

## حدود النسخة
هذه واجهة أولية فقط. تخزن بيانات العرض التجريبية في `localStorage` على نفس المتصفح والجهاز.
لا توفر تسجيل دخول أو صلاحيات Owner حقيقية، ولا تتصل بـ Google Sheets أو قاعدة بيانات.
لا تستخدمها للبيانات الحقيقية أو الحساسة. يلزم بناء Backend ومصادقة آمنة وربط Google API قبل التشغيل الإنتاجي.
