# منصة خدمات الشارع ونادي الكوم الأخضر

تحديث تجريبي يتضمن إضافة بطاقة نشاط «المقاول» في ترسا – الهرم – الجيزة.

## الملفات
- `index.html`: صفحة المنصة بعد إضافة النشاط.
- `.nojekyll`: ملف فارغ مطلوب لنشر الملفات الثابتة على GitHub Pages.

## النشر على المستودع الحالي
ارفع الملفات الثلاثة مباشرة إلى جذر المستودع، مع استبدال `index.html` و`README.md` الحاليين عند الحاجة، واترك `.nojekyll` موجودًا.
