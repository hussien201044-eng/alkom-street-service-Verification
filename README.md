# منصة خدمات الشارع ونادي الكوم الأخضر

منصة ربط تجاري وخدمي مستقلة لخدمة الأهالي والمحلات والفنيين ومقدمي الخدمات المحليين. لا تمثل جهة حكومية أو سلطة محلية، ولا تدّعي اعتمادًا رسميًا.

## النشر على GitHub Pages
1. فك ضغط الحزمة.
2. ارفع `index.html` و`.nojekyll` و`README.md` إلى جذر المستودع (Root).
3. افتح Settings ثم Pages.
4. من Build and deployment اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/(root)` ثم Save.

## ملاحظات قبل الإطلاق
- راجع بيانات المحلات والأسعار وأرقام التواصل؛ قد توجد بيانات تجريبية تحتاج تحديثًا.
- التخزين المحلي يعمل على الجهاز والمتصفح الحاليين فقط، ولا يمثل قاعدة بيانات مركزية.
- GitHub Pages يستضيف ملفات ثابتة ولا يوفر وحده تسجيل دخول آمنًا أو صلاحيات إدارية أو قاعدة بيانات مشتركة.
- لا تستخدم الصفحة لتحصيل أموال أو استقبال مدفوعات قبل تنظيم الجهة المسؤولة ووسيلة الدفع قانونيًا.
- إدراج النشاط في الدليل لا يعني التحقق من جميع تراخيصه أو اعتماده من جهة حكومية.
